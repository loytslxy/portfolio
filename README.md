# 李晓莹 · 个人作品集网站

一个采用杂志式排版的个人作品集单页网站，展示技能方向与项目作品，支持桌面端、移动端适配和深浅色主题切换。

## 技术栈

- **HTML5** — 页面结构
- **CSS3** — 样式与响应式布局（CSS 变量驱动主题）
- **原生 JavaScript** — 数据渲染与交互，无框架、无第三方库

## 运行方式

纯静态项目，无需构建：

1. 直接用浏览器打开 `index.html`；
2. 或使用本地服务器访问（推荐）：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 主要功能

- **首屏介绍** — 个人定位与技能方向概览
- **作品目录** — 项目列表由 `js/projects.js` 数据驱动渲染，新增作品只需向 `PROJECTS` 数组追加一条数据
- **深浅色主题切换** — 导航栏右侧按钮一键切换，选择通过 `localStorage` 持久化，页面背景、文字、边框颜色同步变化
- **移动端适配** — 窄屏下导航折叠为汉堡菜单，作品布局自动退化为上图下文
- **滚动交互** — 导航吸顶、当前区域高亮、内容入视口渐显

## 目录结构

```
lab04/
├── index.html          # 页面入口
├── css/
│   └── style.css       # 全部样式（含深浅色主题变量）
├── js/
│   ├── projects.js     # 项目作品数据
│   └── main.js         # 渲染与交互逻辑
└── assets/             # 图片资源
```
